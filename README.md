# 📊 Customer Churn Analysis Dashboard

## 📌 Project Overview

This project is a **Customer Churn Analysis Dashboard** created using **Microsoft Excel**. The dashboard analyzes customer data to identify churn patterns, customer behavior, payment methods, internet services, and key business metrics.

The main objective of this project is to transform raw customer data into meaningful insights using interactive Excel dashboard techniques.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPIs
- Data Cleaning
- Data Analysis
- Data Visualization

## 📈 Key KPIs

- Total Customers
- Average Monthly Charges
- Average Tenure
- Total Revenue
- Average Total Charges

## 📊 Dashboard Analysis

The dashboard provides insights into:

- Customer Churn
- Customers by Payment Method
- Customers by Internet Service
- Customer behavior and trends
- Key customer and revenue metrics

## 🎯 Key Features

- Interactive dashboard
- KPI cards for important metrics
- Pivot Tables for data analysis
- Pivot Charts for visualization
- Slicers for interactive filtering
- Clean and professional dashboard layout

## 💡 Project Objective

The objective of this project is to practice and demonstrate my skills in **Excel, Data Analysis, Data Visualization, and Dashboard Creation** by analyzing customer churn data and presenting the findings in an easy-to-understand format.
